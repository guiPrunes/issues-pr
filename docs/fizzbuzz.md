# Teste de conhecimento de linguagem: FizzBuzz

## O que é?
O teste FizzBuzz consiste em produzir um algoritmo que verifica se um número n é divisível por 3 ou por 5.

#@ O que o teste retorna?

O teste deve retornar as seguintes respostas:
- "Fizz" - se divisível por 3;
- "Buzz" - se divisível por 5;
- "FizzBuzz" - se diviível por 3 e 5;
- n - se não for divisível por 3 e nem 5;
- "n não é um número" - se n não é um valor inteiro/real;
